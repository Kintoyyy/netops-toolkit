Bulk HTTP Checker

Mass-check domains or URLs — DNS resolution, reachability, response time and status codes, with CSV export and a curl / PowerShell script for exact codes.

Requests go straight from your browser to each site. Browsers hide the status code of cross-origin responses unless the site sends CORS headers, so most results read Responds (the server answered) rather than 200 / 404 / 500 — use the terminal script below for exact codes and redirect targets. Ad-blockers and privacy extensions can make blocked sites look unreachable. Don't probe live malware / phishing IOCs from a workstation — use the script from an isolated host.

Exact status codes & redirects — run the same list from a terminal 

    
Writes http-check.csv. Redirects are not followed, so 3xx rows show where they point. Uses the Parallel and Timeout settings above. Code 000 (curl) / 0 (PowerShell) = no connection, TLS error or timeout.
