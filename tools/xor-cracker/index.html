XOR Cracker

XOR with any key, brute-force single-byte keys, recover repeating keys by Hamming distance, and derive the key from known plaintext like “flag{”.

XOR with a key

Known-plaintext tries every offset and shows key fragments that look like readable text or repeat.

Automatic attacks

Single-byte tries all 256 keys. Repeating-key estimates the key length with normalized Hamming distance (2–40), then solves each column as single-byte XOR. Needs a few dozen bytes per key byte.
